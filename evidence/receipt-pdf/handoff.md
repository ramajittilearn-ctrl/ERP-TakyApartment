## Scope

New `src/server/payments/pdf.ts` renders existing verified ReceiptDto facts into a paginated Thai A4 receipt record. It preserves original amounts/labels/number and appends cancellation separately, with a cancellation banner and missing-legal-issuer notice on every page. There is no ambient issuer configuration, new policy, schema, migration or financial command.

New `src/server/pdf/fonts.ts` holds registration and the accepted Thai/Baht/Helvetica-superscript-three grapheme routing. Existing invoice renderer changes are limited to mechanical extraction/import/calls. Invoice layout and values are unchanged.

New receipt-ID `GET /api/v1/receipts/[id]/pdf/` reuses requireActor/getReceipt, returns private no-store inline PDF, supports only explicit `download=1` attachment and rejects unknown/duplicate/invalid queries before receipt loading. Error responses use the existing sanitized JSON handler. Existing receipt screen gains native same-origin new-tab open/print and download links and an explicit record-only issuer notice.
